# S2J Query Pinned

一覧の先頭にピン留めを置き、残りを別の順で並べる WordPress プラグインです。判断の正は [S2J Query Pinned Service](https://github.com/stein2nd/s2j-query-pinned-service) にあります。

実行環境は PHP v8.3以降です (WordPress [必須要件](https://ja.wordpress.org/about/requirements/)に合わせる)。

確定前の仕様は [docs_mod/specs.md](docs_mod/specs.md) です。
